## Featured Projects

- [sentinel](https://github.com/Ansh-Sonkusare/sentinel): Policy-guarded agent payment router. An LLM plans a task graph, each step is paid via x402 on Algorand and validated by a policy guard.
- [undercut](https://github.com/Ansh-Sonkusare/undercut) and [fastf1](https://github.com/Ansh-Sonkusare/fastf1): Formula 1 race-strategy terminal with lap-by-lap replay and pit calls with confidence, plus the OpenF1 TypeScript client with React hooks that powers it.
- [midnight-poker](https://github.com/Ansh-Sonkusare/midnight-poker): Provably fair Texas Hold'em on Midnight with ZK shuffle proofs and private hole cards.
- [ribozome](https://github.com/Ansh-Sonkusare/ribozome): Private, non-custodial cross-chain yield and liquidity protocol.
- [hhgoa-fraud-agent](https://github.com/Ansh-Sonkusare/hhgoa-fraud-agent): LLM agent that investigates card-fraud alerts on TigerGraph and files suspicious activity reports. Related tooling: [gsql-treesitter](https://github.com/Ansh-Sonkusare/gsql-treesitter), [gsql-vscode](https://github.com/Ansh-Sonkusare/gsql-vscode).
- [Dendro](https://github.com/Ansh-Sonkusare/Dendro): Nix flake for WSL, a k3s homeserver and macOS (home-manager, nix-darwin, sops-nix, disko, deploy-rs).
- [PBL](https://github.com/Ansh-Sonkusare/PBL): Blockchain attendance tracker with rotating QR codes, geofencing and gasless ERC-2771 anchoring.
- [reading-together](https://github.com/Ansh-Sonkusare/reading-together): Shared e-book reader for couples with live notes and reactions.
